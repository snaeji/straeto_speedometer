# IMPLEMENTATION_PLAN.md

## Straeto Speedometer -- Complete Implementation Plan

### Overview

A monorepo containing three Dart packages:
1. **`shared/`** -- Pure Dart library with models, API client, speed calculation, and speed limit matching (no Flutter dependency)
2. **`app/`** -- Flutter web application (imports `shared/`)
3. **`collector/`** -- Dart CLI script for long-running data collection (imports `shared/`)

Plus tooling:
4. **`tools/download_speed_limits.dart`** -- Script to download and bundle speed limit GeoJSON
5. **`.github/workflows/deploy.yml`** -- GitHub Actions workflow for GitHub Pages deployment

#### File 1.6: `shared/lib/src/services/geo_utils.dart`

Pure math utilities with no external dependencies:

- `double haversineDistanceM(double lat1, double lng1, double lat2, double lng2)` -- Standard Haversine formula returning meters. Use Earth radius 6371000m.
- `double pointToLineSegmentDistanceM(double pLat, double pLng, double aLat, double aLng, double bLat, double bLng)` -- Perpendicular distance from point to line segment, in meters. Uses flat-Earth approximation with Reykjavik-specific degree-to-km conversions (sufficient accuracy for <50m distances). Project point onto segment, clamp to endpoints, then Haversine for final distance.
- `double speedKmh(double distanceM, int timeDeltaS)` -- Simple `(distanceM / 1000) / (timeDeltaS / 3600)`.

This file has no dependencies on other project files.

#### File 1.7: `shared/lib/src/models/bus_location.dart`

Core data model used everywhere:

```dart
class BusLocation {
  final String busId;
  final String routeNr;
  final String tripId;
  final double lat;
  final double lng;
  final int direction;
  final int timestamp;          // Unix epoch milliseconds
  final String? headsign;
  final double? speedKmh;       // null if not yet calculated
  final double? speedLimitKmh;  // null if not matched
  final bool isViolation;       // false if speed or limit is null

  const BusLocation({...});     // All fields in constructor

  // Named constructor from Straeto API JSON + timestamp
  factory BusLocation.fromApiJson(Map<String, dynamic> json, int timestamp);

  // JSON Lines serialization (for collector output and import)
  factory BusLocation.fromJsonLine(Map<String, dynamic> json);
  Map<String, dynamic> toJsonLine();

  // copyWith for updating speed/violation fields after calculation
  BusLocation copyWith({double? speedKmh, double? speedLimitKmh, bool? isViolation});
}
```

The `fromApiJson` factory maps API fields:
- `busId` from `json['busId']` (String)
- `routeNr` from `json['routeNr']` (String)
- `tripId` from `json['tripId']` (String)
- `lat` from `json['lat']` (double)
- `lng` from `json['lng']` (double)
- `direction` from `json['direction']` (int)
- `headsign` from `json['headsign']` (String?)
- `timestamp` passed as argument (from the response-level `lastUpdate` parsed to epoch ms)
- `speedKmh`, `speedLimitKmh` initially null
- `isViolation` initially false

The `toJsonLine()` outputs compact JSON with short keys to minimize file size:
```json
{"b":"1-A","r":"1","t":"63714","la":64.134,"ln":-21.905,"d":109,"ts":1741651200000,"h":"Hfj.","s":45.2,"sl":50,"v":false}
```

Key mapping: `b`=busId, `r`=routeNr, `t`=tripId, `la`=lat, `ln`=lng, `d`=direction, `ts`=timestamp, `h`=headsign, `s`=speedKmh, `sl`=speedLimitKmh, `v`=isViolation.

  /// Returns tuple of (timestamp in epoch ms, list of BusLocation).

Implementation details:

- Parse `data.BusLocationByRoute.results` array, constructing `BusLocation.fromApiJson()` for each, passing the parsed timestamp
- Throw descriptive exceptions on HTTP errors or malformed responses
- No retry logic here -- callers handle that

#### File 1.10: `shared/lib/src/services/speed_calculator.dart`

Implements the 4-step speed calculation pipeline from CLAUDE.md:

```dart
class SpeedCalculator {
  // Per-bus state: buffer of recent positions for smoothing
  final Map<String, List<_PositionFix>> _busBuffers = {};

  /// Process a new GPS fix for a bus. Returns the BusLocation
  /// with speedKmh filled in (or null if rejected by Step 1).
  BusLocation? processFix(BusLocation location) { ... }

  /// Reset state for a specific bus (e.g., on route change)
  void resetBus(String busId) { ... }

  /// Reset all state
  void resetAll() { ... }
}

class _PositionFix {
  final double lat;
  final double lng;
  final int timestamp;  // epoch ms
}
```

The `processFix` method implements:

**Step 1 -- Outlier Rejection:**
- If this bus has a previous fix in `_busBuffers`:
  - Compute distance via `haversineDistanceM()` between new and last fix
  - Compute time delta in seconds
  - REJECT (return null) if: distance > 500m, OR computed speed > 120 km/h, OR timeDelta < 1s
- If no previous fix, store this as first fix, return location with `speedKmh = 0`

**Step 2 -- Minimum Distance Threshold:**
- If distance between this fix and previous fix < 10m, set `speedKmh = 0` on the result
- Still add the fix to the buffer (it's valid, just stationary)

**Step 3 -- Position Smoothing:**
- Add the new `_PositionFix` to this bus's buffer
- Keep only the last 3 fixes in the buffer
- Compute smoothed lat/lng as arithmetic mean of all fixes in buffer
- If buffer has >= 2 entries, compute speed from the previous smoothed position to current smoothed position using Haversine
- Store the current smoothed position for next iteration

**Step 4 -- Conservative Speed Factor:**
- Multiply the speed from Step 3 by 0.92
- This is the final `speedKmh` value

Special case: if `speedKmh` was set to 0 in Step 2, skip Steps 3-4 (keep it at 0).

Return `location.copyWith(speedKmh: computedSpeed)`.

#### File 1.11: `shared/lib/src/services/speed_limit_service.dart`

Loads GeoJSON speed limit data and matches GPS coordinates to road segments:

```dart
class SpeedLimitService {
  List<SpeedLimitSegment> _segments = [];
  bool get isLoaded => _segments.isNotEmpty;

  /// Load segments from parsed GeoJSON FeatureCollection.
  void loadFromGeoJson(Map<String, dynamic> geoJson) { ... }

  /// Find the speed limit at a given GPS coordinate.
  /// Returns the HRADI value of the nearest segment within 50m,
  /// or 50.0 (default urban) if none found.
  double getSpeedLimit(double lat, double lng) { ... }
}
```

The `getSpeedLimit` method:
1. Iterate all segments (brute force -- ~10K segments is fast enough)
2. For each segment, compute minimum distance from (lat, lng) to any line sub-segment using `pointToLineSegmentDistanceM()`
3. Track the segment with the smallest distance
4. If smallest distance <= 50m, return that segment's `speedLimitKmh` as double
5. Otherwise return `defaultSpeedLimitKmh` (50.0)

A `LineString` geometry has N coordinates forming N-1 sub-segments. For each consecutive pair of coordinates in the LineString, compute point-to-segment distance and take the minimum.

#### File 3.1: `tools/download_speed_limits.dart`

// Output: app/assets/speed_limits.geojson

Implementation:
1. Define the base query URL: `https://borgarvefsja.reykjavik.is/arcgis/rest/services/Borgarvefsja/Borgarvefsja_over/MapServer/23/query`
2. Define query params: `where=1%3D1&outFields=*&f=geojson&outSR=4326&returnGeometry=true&resultRecordCount=2000`
3. Loop through 5 pages (offsets: 0, 2000, 4000, 6000, 8000):
   - Fetch `{baseUrl}?{params}&resultOffset={offset}`
   - Parse response as JSON
   - Extract `features` array
   - Print progress: `"Page {n}/5: got {count} features"`
4. Merge all features into a single GeoJSON FeatureCollection:
   ```json
   {
     "type": "FeatureCollection",
     "features": [... all merged features ...]
   }
   ```
5. Write to `app/assets/speed_limits.geojson`
6. Print summary: total features, file size, speed limit distribution

This script needs its own implicit dependency on `dart:io` and `dart:convert`. It uses `HttpClient` from `dart:io` directly (no package dependency needed). It should be run from the project root directory.

#### File 4.3: `collector/lib/collector_service.dart`

The main collection loop:

```dart
class CollectorService {
  final StraetoApi _api;
  final SpeedCalculator _speedCalculator;
  final SpeedLimitService _speedLimitService;
  final JsonlWriter _writer;
  final Duration _interval;

  // Deduplication: track last seen timestamp per busId
  final Map<String, int> _lastSeenTimestamp = {};

  // Stats
  int totalRecords = 0;
  int totalViolations = 0;
  DateTime? startTime;

  Future<void> start() async { ... }
  void stop() { ... }
}
```

The `start()` method:
1. Set `startTime = DateTime.now()`
2. Enter a loop (while not stopped):
   a. Call `_api.fetchBusLocations()` -- get `(timestamp, buses)`
   b. For each bus in `buses`:
      - **Deduplicate**: if `_lastSeenTimestamp[bus.busId] == timestamp`, skip (GPS hasn't updated)
      - Update `_lastSeenTimestamp[bus.busId] = timestamp`
      - Call `_speedCalculator.processFix(bus)` -- returns `BusLocation?` (null = rejected)
      - If not null, call `_speedLimitService.getSpeedLimit(bus.lat, bus.lng)` to get speed limit
      - Set `isViolation = speedKmh != null && speedLimitKmh != null && speedKmh > speedLimitKmh`
      - Call `bus.copyWith(speedLimitKmh: limit, isViolation: violation)`
      - Write to JSONL via `_writer.write(bus)`
      - Increment counters
   c. Wait for `_interval` duration
   d. On API error: print warning, continue (don't crash)
3. Print periodic stats every 60 seconds: records/min, active buses, violations

### API Details Reference

#### Straeto GraphQL API

**Request:**
```
POST https://api.straeto.is/graphql
Content-Type: application/json

{
  "extensions": {
    "persistedQuery": {
      "version": 1,
      "sha256Hash": "8f9ee84171961f8a3b9a9d1a7b2a7ac49e7e122e1ba1727e75cfe3a94ff3edb8"
    }
  },
  "variables": {
    "routes": ["1", "2", "3", ..., "36"]
  }
}
```

**Response:**
```json
{
  "data": {
    "BusLocationByRoute": {
      "lastUpdate": "2026-03-10T21:56:11.000Z",
      "results": [
        {
          "busId": "1-A",
          "tripId": "63714",
          "routeNr": "1",
          "tag": null,
          "headsign": "Hfj. Skardshlid",
          "lat": 64.1342297166667,
          "lng": -21.9057193333333,
          "direction": 109,
          "__typename": "BusLocationByRouteRoutes"
        }
      ],
      "__typename": "BusLocationByRoute"
    }
  }
}
```

**Notes:**
- `lastUpdate` is per-response, NOT per-bus
- `tag` field exists but is always null (ignore it)
- `direction` is an integer (degrees, 0-360)
- CORS: `access-control-allow-origin: *` (no proxy needed)
- Cache: `max-age=2` (poll every 2 seconds)
- Variable name is `routes` (plural, array of strings)

#### Borgarvefsja Speed Limit API

**Request (paginated):**
```
GET https://borgarvefsja.reykjavik.is/arcgis/rest/services/Borgarvefsja/Borgarvefsja_over/MapServer/23/query
  ?where=1%3D1
  &outFields=*
  &f=geojson
  &outSR=4326
  &returnGeometry=true
  &resultRecordCount=2000
  &resultOffset={0,2000,4000,6000,8000}
```

**Response:** Standard GeoJSON FeatureCollection. See CLAUDE.md for field details.

### Potential Challenges and Mitigations

1. **GeoJSON asset size (~5-10 MB):** This is loaded at app startup. Parse asynchronously to avoid blocking the UI. The speed limit matching is brute-force O(N) per query over ~10K segments. At typical usage (50 buses, 0.5 queries/second per bus = 25 queries/second), this should be fine on modern hardware. If slow, add a simple grid-based spatial index (bucket segments into 0.01-degree cells).

2. **IndexedDB performance for large datasets:** After days of collection, the database could hold millions of records. Stats computation must stream data in chunks rather than loading everything into memory at once. The `getAllLocationsStream` method handles this.

3. **Browser tab memory:** Keeping all live bus positions in memory is fine (at most ~60 buses). For playback/stats, only load the time window needed.

4. **API reliability:** The Straeto API may occasionally fail or return errors. Both the collector and browser collection should handle errors gracefully (log and retry on next cycle, don't crash).

5. **flutter_map_marker_cluster compatibility:** The package version 8.2.2 matches flutter_map 8.2.2. Pin both to `^8.2.2`.

6. **Heatmap without flutter_map_heatmap:** Since the heatmap package is incompatible with flutter_map 8.x, use a custom `CircleLayer`-based approach. Semi-transparent red circles at violation points create a visual density effect when they overlap.

7. **GitHub Pages base href:** The `--base-href` flag in the build command ensures assets load correctly from the subpath. The `index.html` must have `<base href="/">` for local development (the CI build overrides this).
